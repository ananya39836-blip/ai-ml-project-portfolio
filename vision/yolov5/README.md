# YOLOv5 Object Detection System

This project implements a **YOLOv5 (You Only Look Once, version 5) object detection system** for real‑time image and video analysis.  
YOLOv5 is a state‑of‑the‑art deep learning model that achieves high accuracy and speed in detecting multiple objects simultaneously.

---

## Features
- Real‑time object detection on images, video streams, or webcam input
- Outputs bounding boxes, class labels, and confidence scores
- Built on PyTorch with OpenCV integration for visualization
- Easily extendable to custom datasets for transfer learning
