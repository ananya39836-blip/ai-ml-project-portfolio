# Text-to-Speech Demo (gTTS5)

This project demonstrates a **text-to-speech (TTS) system** using the Google Text-to-Speech (gTTS) library.  
It converts written text into spoken audio and saves the output as an MP3 file.  
This simple yet powerful tool can be used for accessibility, voice assistants, or multimedia applications.

---

## Features
- Converts plain text into natural-sounding speech
- Supports multiple languages and accents
- Saves audio output as MP3 files
- Lightweight and easy to integrate into larger projects
